Create a public repository named exactly **MutahharBaig** under your account. If it already exists, edit that repository instead.

Upload the **contents** of the included MutahharBaig folder to the repository root:
- README.md
- assets/banner.gif

Add project screenshots or actual demo GIFs inside the individual project READMEs, followed by the problem, your contribution, hardware/software requirements, run instructions, and evaluation limits. Do not publish employer or client code without permission. A public project case study can document work without exposing private code.
