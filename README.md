## Software that works beyond the screen.

I'm **Mutahhar**, an Electronics Engineering graduate from **UET Taxila**, based in Islamabad, Pakistan. I develop embedded firmware, work with audio and vision pipelines, and deploy machine-learning models on edge hardware.

My projects connect **C/C++ and Python** with microcontrollers, sensors, and Rockchip processors—from interactive audio devices to agricultural robotics.
